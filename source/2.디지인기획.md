**아우렐리스 웹사이트 디자인 기획**

미니멀 럭셔리 레퍼런스를 실제 화면과 제작 자산으로 전환하는 가이드

기획 문서  |  2026.10  |  웹사이트 구축을 위한 기준안

디자인의 목표는 제품의 조형미와 피부의 투명한 질감을 조용하게 드러내는 것이다. 화이트 여백과 인크 블랙의 대비, 유리·물·섬세한 직물의 움직임을 중심으로 구성하며, 장식보다 제품과 메시지의 호흡을 우선한다.

**3 히어로와 핵심 모션**

홈 히어로는 ‘제품이 떠 있는 것처럼 보이는’ 정적인 장면을 우선 제작한다. 영상은 이를 확장한 대체 자산으로, 제품 주변의 반투명 천이나 수면 반사가 천천히 이동하는 장면을 권장한다. 최초 로딩 시 영상이 지연되면 포스터 이미지가 즉시 노출되도록 설계한다.

|             |           |                                          |
| ----------- | --------- | ---------------------------------------- |
| **모션**      | **길이**    | **규칙**                                   |
| 히어로 루프      | 6–10초     | 무음·무자막·끊김 없는 루프. 2MB 내외 WebM 우선, MP4 대체. |
| 스크롤 진입      | 0.5–0.8초  | 불투명도와 8–16px 이동만 사용. 과도한 스크롤 연동 금지.      |
| 제품 3D 또는 회전 | 선택 사항     | MVP에서는 3장 전환으로 대체 가능. 제작 여유가 있을 때만 도입.   |
| 버튼·폼        | 0.15–0.2초 | 색·테두리 변화 중심. 모션 민감 사용자 설정을 존중.           |

**5 모바일 대응**

데스크톱의 긴 카피는 모바일에서 2–3줄의 핵심 문장으로 압축하고, CTA는 첫 화면 안에 유지한다.

히어로는 4:5 세로 크롭을 별도 제작한다. 중앙 제품이 가려지지 않도록 안전 영역을 상·하 12% 확보한다.

제품 카드 4열은 2열 또는 가로 스크롤로 전환한다. 이미지는 lazy loading을 적용하되 첫 화면 이미지는 우선 로드한다.

prefers-reduced-motion 환경에서는 영상 자동재생과 패럴랙스를 정지 이미지로 바꾼다.

**7 촬영 및 생성 시 주의**

AI 생성 이미지를 활용할 경우에는 손·용기 라벨·액체 물리 표현을 확대 검수하고, 실제 판매 제품의 패키지와 불일치하지 않도록 제품 합성은 최종 실사 팩샷을 기준으로 진행한다. 인물 초상 사용은 모델 릴리스, 음원은 사용권, 폰트는 웹폰트 라이선스를 별도로 확인한다.
